# Firmware

ESPHome configuration for the Chaac controller (ESP8266).

> 🚧 The ESPHome YAML from the thesis (Appendix 9.3) is being added.

## Setup

1. Install ESPHome: `pip install esphome`, or use the Home Assistant add-on.
2. `cp secrets.yaml.example secrets.yaml` and fill in your values.
3. Flash the board: `esphome run chaac.yaml`
