# Conclusions

Summary of Chapter 7 of the thesis.

1. **Operational efficiency.** Automatic pH and EC control removes the daily manual measurements and adjusts the solution as the crop needs it.
2. **Scalable profitability.** The system pays for itself from the second year, and the return grows with the number of modules (see [results.md](results.md)).
3. **Accurate measurements.** With calibration, the sensors keep pH and EC in the desired ranges (0.23 % and 0.61 % error against handheld meters).
4. **Ease of use.** Home Assistant plus VPN access lets operators monitor and adjust setpoints from anywhere.
5. **Process analysis.** The farm's full hydroponic process was analyzed for automation potential.
6. **Hardware selection.** Parts were chosen with a structured method (see [design-process.md](design-process.md)).
7. **Software.** Control logic, communication and the user interface met the client's needs.
8. **Validation.** Five tests confirmed measurement, dosing and control.

The author's recommendations for future work are tracked in [ROADMAP.md](../ROADMAP.md).
