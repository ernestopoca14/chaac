# Branding

Put the Chaac emblem here as `chaac_glyph.svg`.

Design guidance:

- Draw an **original**, simplified glyph (curled nose, raindrop, lightning axe). Don't trace someone else's modern drawing.
- Use a single closed path with no strokes, so OpenSCAD can import it.
- Make it square-ish. `hardware/enclosure/lid.scad` scales it to `emblem_size`.
